# متجر عالم الأسمنت — مأرب، اليمن

متجر إلكتروني + تطبيق ويب (PWA) + لوحة إدارة، بدون أي اعتماديات خارجية (Node.js 22 وقاعدة SQLite المدمجة).

## لماذا هذه التقنية (وليس Next.js + Supabase)؟
- المشروع **بلا حزم npm**: لا شيء يتعطل عند التحديث، وتشغيله أبسط، وقد اختُبر كاملًا.
- قاعدة SQLite ملف واحد: نسخها احتياطيًا واستعادتها سهلة، وتدعم العمليات الذرّية التي تمنع بيع الكمية مرتين.
- المقابل: تحتاج استضافة **بقرص دائم** (مدفوعة). لا تصلح استضافات بلا قرص دائم مثل Vercel لأن البيانات تُفقد.

## التشغيل محليًا
```bash
node -v                       # يجب أن يكون 22.13 أو أحدث
export ADMIN_USER=admin ADMIN_PASSWORD='كلمة-مرور-قوية-8+'
npm start                     # المتجر: http://localhost:3000  | الإدارة: http://localhost:3000/admin
npm test                      # 14 اختبارًا
```
قاعدة البيانات تُنشأ تلقائيًا في `data/`. حساب المدير يُنشأ عند أول تشغيل، أو بالأمر `npm run create-admin`.
أضف من لوحة الإدارة: **المنتجات ← إدارة المصانع** ثم **منتج جديد**، ثم **التوصيل** لإضافة المناطق، ثم **الإعدادات** لمراجعة العنوان والواتساب.

## النشر من GitHub (مثال Render)
1. ارفع محتويات هذا المجلد إلى مستودعك (Add file ← Upload files ← Commit).
2. في render.com: New ← Blueprint ← اختر المستودع (يقرأ `render.yaml`).
3. عيّن `ADMIN_USER` و `ADMIN_PASSWORD` عند الطلب. القرص الدائم مضبوط على `/data`.
4. بعد النشر تحصل على رابط `https://...onrender.com` تشاركه مع العملاء. HTTPS تلقائي.
5. **التحديث**: أي تعديل ترفعه إلى GitHub يُنشر تلقائيًا، والـPWA عند العملاء يتحدث وحده عند فتحه (دون إعادة تثبيت).
6. **نطاق خاص**: اشترِ نطاقًا من أي مسجّل، ثم في Render: Settings ← Custom Domains وأضف سجل CNAME الذي يعطيك إياه.
بدائل: Railway أو Fly.io (مع Volume) أو أي VPS: `docker build -t cement . && docker run -d -p 80:3000 -v /srv/cement:/data -e ADMIN_USER=.. -e ADMIN_PASSWORD=.. cement` مع Caddy/Nginx لـHTTPS.

## تثبيته على الهاتف
افتح الرابط في Chrome ← القائمة ← «تثبيت التطبيق» (أو «إضافة إلى الشاشة الرئيسية»). في iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
دون اتصال: تُعرض آخر نسخة من المنتجات للتصفح فقط، ولا يمكن إرسال الطلبات ولا يُؤكَّد أي سعر أو مخزون إلا من الخادم.

## النسخ الاحتياطي والاستعادة
- من اللوحة: **الإعدادات ← تنزيل نسخة احتياطية** (قاعدة البيانات).
- على الخادم: `npm run backup` (قاعدة + الصور، يحتفظ بآخر 30 نسخة)، ويُجدول يوميًا بـcron.
- الاستعادة (بعد إيقاف الخادم): `npm run restore -- backups/الملف.db`.

## كيف يعمل نظام الأسعار والطلبات
- التجزئة: عامة، وتُحسب كل الأسعار والخصومات **على الخادم** (لا يُصدَّق أي سعر من المتصفح). تغيّر السعر بعد الإضافة للسلة يُنبّه العميل ويرفض الإرسال حتى يراجعه.
- الجملة: لا أسعار عامة. العميل يرسل «طلب تسعير» ← تحدد أنت سعر كل بند ← «إرسال عرض السعر» ← يوافق العميل من رابط المتابعة (أو تسجّل موافقته هاتفيًا) ← يتأكد الطلب. السعر خاص بالطلب ولا يغيّر سعر التجزئة.
- التوصيل: تحدد أنت أجرة النقل لكل طلب، ويصل العميل عرض بالإجمالي ليوافق. الاستلام من المستودع بلا أجرة، وطلب التجزئة للاستلام يمكن قبوله مباشرة.
- المخزون: **الحجز** عند تأكيد الطلب (يرفض إن تجاوز المتاح)، و**الصرف النهائي** عند تسجيل «التسليم»، وإلغاء الطلب المحجوز يعيد الكمية. كل حركة مسجلة باسم المستخدم.
- الدفع: نقدي أو تحويل. لا يُعدّ الطلب «مكتمل الدفع» إلا بعد تسجيلك للتحصيل الكامل بعد التسليم. التحويل يبقى «بانتظار التحقق».
- الحالات الاثنتا عشرة مطبّقة، والعميل يرى سجلًا زمنيًا للتحديثات المخصصة له فقط.
- الفواتير: طلب غير مؤكد ← عرض سعر ← أمر بيع مؤكد ← فاتورة بيع (رقم تسلسلي عند التسليم) ← فاتورة مكتملة. الطباعة/PDF من زر «طباعة / حفظ PDF» في المتصفح.

## الصلاحيات
- **مدير**: كل شيء (المنتجات والأسعار والتقارير والمستخدمون والإعدادات والنسخ الاحتياطي).
- **موظف**: الطلبات والعملاء والتوصيل وحركة المخزون فقط.

## الأمان
كلمات المرور مُشفّرة (scrypt)، جلسات HttpOnly، حماية CSRF، تحديد محاولات الدخول، روابط متابعة عشوائية 192 بت، سياسة CSP، فحص نوع الصور المرفوعة، وسجل بعمليات الإدارة.

## واتساب
رقم المتجر 775477377 (الدولي المفترض 967775477377 — عدّله من الإعدادات إن اختلف). الأزرار تفتح محادثة واتساب جاهزة النص (ملخص الطلب + رابط المتابعة) وترسلها أنت يدويًا.
**الإرسال الآلي غير مُفعّل**: يتطلب حساب WhatsApp Business Cloud API من Meta (توثيق نشاط ورقم مخصص، وتكلفة حسب المحادثات)، ويمكن إضافته لاحقًا في `server/app.js`.

## التكاليف المحتملة
- استضافة بقرص دائم: نحو 7 دولارات شهريًا تقريبًا (Render Starter + قرص 1GB) — تحقق من الأسعار الحالية قبل الاشتراك.
- النطاق الخاص (اختياري): نحو 10–15 دولارًا سنويًا.
- لا يوجد أي اشتراك آخر. بوابة دفع إلكتروني: غير مضافة (لا مزود مؤكد في اليمن).

## ما لم يُنفَّذ بعد
- حسابات العملاء (الدخول وحفظ العناوين): الشراء بلا حساب يعمل، والعميل يرى طلباته على جهازه.
- تقارير الأرباح ومصروفات النقل التفصيلية: المسجَّل أجرة النقل على الطلب فقط.
- أسعار الشرائح الكمية التلقائية: تُسعَّر طلبات الجملة يدويًا، مع سعر مرجعي وأسعار خاصة للعملاء المعتمدين.
